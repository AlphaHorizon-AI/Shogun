# Shogun IDE Bridge

Local VS Code adapter for Shogun IDE Mode. Enable IDE Mode in Campaign or Ronin, create a one-time pairing token in Katana, then run **Shogun: Connect IDE Bridge**.

The extension connects only to localhost by default and registers the current workspace. Shogun remains the authority for posture, permissions, workspace approval, file boundaries, task commands, Git operations, snapshots, and audit events.
