# Shogun 1.45.0

## Privacy-preserving installation telemetry

- Adds explicit, unbundled, default-off consent in native installers and The Tenshu.
- Adds strict pseudonymous install, update, weekly heartbeat, revocation, and test events.
- Adds local preview, withdrawal, remote deletion, bounded offline queue, and clone-safe identity rotation.
- Adds an Alpha Horizon ingestion service with HMAC identifiers, hashed tokens,
  retention maintenance, aggregate adoption metrics, and SSO/MFA proxy enforcement.
- Adds Docker fail-closed controls, distribution metadata, privacy documentation,
  and CI privacy release gates.

The service is not production-enabled by repository code alone. EU hosting,
privacy notice publication, legal review, processor agreements, SSO/MFA
provisioning, WAF, monitoring, backups, and packet-capture validation remain
controlled-launch gates.
